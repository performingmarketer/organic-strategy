# Organic Strategy — Installation and Usage

## മലയാളം: Claude-ൽ Skill ചേർക്കുന്നത്

1. ഈ GitHub Repository-യിൽ **Code → Download ZIP** ക്ലിക്ക് ചെയ്യുക.
2. ZIP extract ചെയ്ത ശേഷം `SKILL.md`, `references/`, `examples/` എന്നിവ അടങ്ങിയ ഫയലുകൾ `organic-strategy` എന്ന folder-നകത്ത് വെക്കുക.
3. `organic-strategy` എന്ന folder ZIP ആക്കുക. ZIP തുറക്കുമ്പോൾ `organic-strategy/SKILL.md` ഉണ്ടായിരിക്കണം.
4. Claude-യിലെ **Skills** upload option ലഭ്യമായ account/workspace-ൽ ആ ZIP upload ചെയ്ത് enable ചെയ്യുക. UI menu names മാറാം.
5. ഉപയോഗിക്കുക: `Organic Strategy: Create a 30-day SEO and Malayalam Instagram content calendar for a local Kerala business.`

## മലയാളം: ChatGPT-ൽ ഉപയോഗിക്കുന്നത്

1. [`chatgpt-custom-gpt-instructions.txt`](chatgpt-custom-gpt-instructions.txt) തുറക്കുക.
2. Instructions പുതിയ ChatGPT conversation-ൽ paste ചെയ്യാം. Custom GPT creation support ലഭ്യമെങ്കിൽ GPT Instructions-ലും ഉപയോഗിക്കാം.
3. Detailed planning-ന് `references/`-ലെ relevant markdown files ഉൾപ്പെടുത്തുക.
4. **ZIP upload ചെയ്താൽ സാധാരണ chat-ൽ സ്വയം Skill install ആകില്ല.**

## English

- For compatible Claude Skills interfaces, ZIP the directory `organic-strategy/` (with `SKILL.md` directly under it) and upload it through Skills.
- For ChatGPT, paste `chatgpt-custom-gpt-instructions.txt` as GPT instructions or into a chat. Optionally attach relevant reference files.
- Confirm uploaded skills using the target platform's own instructions; no installation, indexing, Search Console access, publishing, or ranking is guaranteed by this package.
