# Organic Strategy v1.1

**Local SEO + Malayalam Organic Content + Search-to-Social-to-Enquiry** — an independent open-source AI Skill by **Performing Marketer**. Companion to [Ad Strategy](https://github.com/performingmarketer/ad-strategy) for Meta Ads creative planning.

## Purpose: one question, multiple useful outcomes

Use **real customer questions** to improve a relevant website/service page, develop a **natural Malayalam Reel or Carousel**, and offer an honest next action that can lead to **qualified, verified enquiries**. SEO, Google Maps and social are **different surfaces**: never claim one directly controls the others.

### What makes this release more practical

| Module | v1.1 workflow |
|---|---|
| Local SEO / Kerala focus | Storefront vs service-area vs online-only; GBP eligibility and privacy; Maps vs organic distinction; truthful location pages and enquiry paths |
| Malayalam-first editorial | Native code-mixed scripts, realistic voiceover pacing, multiple hook angles, checked spelling and evidence |
| Search-to-Social Bridge | Source of Truth Card → intent/page → Reel → checklist Carousel → optional GBP/community adaptation → destination CTA |
| Qualified enquiry measurement | Verified lead definitions, UTM where possible, privacy-aware ledger, self-reported vs tracked vs unknown source |
| Research and benchmarking | Actual-source/competitor gap review; no fake rank, volume, location presence or originality claims |
| Sustainable calendar | 30-day integrated workplan (not 30 forced posts), 90-day prioritization and capacity controls |

## Installation and use

See [INSTALLATION_GUIDE.md](INSTALLATION_GUIDE.md) for step-by-step English and Malayalam instructions.

**Claude compatible Skills:** Use **Code → Download ZIP** to download this repository, extract it, and place its files inside a folder named `organic-strategy` (containing `SKILL.md`), then ZIP that folder for skill upload. You can also use the separately distributed `organic-strategy-skill-v1.1.zip` archive. In accounts supporting custom skill upload, use the Skills upload interface and select the ZIP. Exact interface varies by account/product. If upload is not supported, use the instructions in project context instead.

**ChatGPT:** Paste `chatgpt-custom-gpt-instructions.txt` into a chat or, if Custom GPT creation is available, use GPT Instructions and add reference files as Knowledge. A ZIP in an ordinary chat is **not** an installed skill. Compatible agents can consume the `organic-strategy` folder per their own procedures.

**First prompt:**

> Organic Strategy: Full Local Growth Sprint for a practical digital marketing training institute in Thrissur. Audience: students who completed a course but need hands-on experience. Malayalam Reels + useful SEO pages + qualified WhatsApp enquiries. I have no Search Console data. 3 posts per week. No placement guarantees.

**Alternate modes:** `SEO Focus`, `Social Focus`, `Quick Plan`, `Single Asset`, `Audit / Refresh`, `Repurpose`, `Local Growth Sprint`, `Malayalam Search-to-Social`, `Competitor / Content Gap`.

## Responsible marketing boundaries

This skill **does not automatically access your website, crawl Search Console, inspect Instagram analytics, publish posts or operate WhatsApp/CRM**. It can propose audits, content and tracking; current data needs authorized tools and available access. Search rankings, AI citations, viral reach and admissions/sales are **never guaranteed**. Validate all local business claims, photos, reviews, consent, platform features and business offers. No fake reviews, cloned city doorway pages, or job-placement guarantees.
