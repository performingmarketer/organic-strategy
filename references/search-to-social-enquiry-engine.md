# Search → Social → Qualified Enquiry: execution engine

**Positioning:** bring together customer questions, reliable searchable answers, native social teaching and an accessible next action. Organic content may create trust even when a single post receives no click; don't force direct-response CTAs onto every educational asset.

## The Source of Truth Card (required for repurposing)

| Field | Record |
|---|---|
| Source ID + title | Unique editorial ID, customer question, owner |
| Origin | Confirmed live page URL / user-supplied document / supplied expert explanation / **hypothesis** |
| Claims and evidence | Exact factual statement, evidence/quote/source, last verified date; label unknown |
| Audience and stage | Discover / compare / decide / existing customer |
| Search anchor | Existing or **proposed** page, search intent, relevant region/language |
| Reuse permissions | Photo/video/quote copyright & customer consent status |
| Native adaptations | Reel, carousel, Story, Facebook text, optional truthful GBP update |
| Destination | Actual service/contact path when user supplies one, otherwise **CTA placeholder** |
| Attribution | UTM where clickable and supported, post/source code in enquiry notes, self-report question |
| Review | Expert + Malayalam proofread + privacy review + publishing approval |

## Source-to-format decisions (not duplication)

| Touchpoint | Unique reader/viewer job | Recommended angle | Important limitation |
|---|---|---|---|
| Existing service landing page | Know what is offered, local fit, proof, action | Specific service or course details; honest objections | Do not promise technical ranking without data |
| Helpful blog/FAQ | Solve the exact customer question | Worked example, useful comparison, original information | Avoid scaled thin content / invented expertise |
| Instagram Reel | Understand one insight quickly | Demonstration, practical mistake or verified myth correction | Instagram feed caption URLs are commonly not clickable; check current available linking features |
| Instagram Carousel | Save a decision checklist | Stepwise comparison or compact decision aid | Text concise and mobile readable |
| Stories / Facebook | Ask or discuss; gain local trust | Q&A, behind-the-scenes, community detail | Respect group rules and DM consent |
| Google Business Profile post | Inform real visitors, only if eligible and appropriate | Truthful offer/service update | No promise that posting frequency boosts rankings |

## Five-step production loop

1. **Choose:** pick one high-value question from real customers, verified site analytics, reviews with permission or clearly labeled hypothesis.
2. **Research/verify:** inspect the original evidence, make a Source of Truth Card, list unverified claims.
3. **Publish/refresh owned answer:** a relevant helpful page, FAQ or service-page improvement; include actual author/process evidence and factual CTA.
4. **Adapt natively:** make a 30–45s Malayalam Reel with 3 hook options, a checklist carousel, and a short local-community post from different angles; preserve claims and attribution.
5. **Learn:** check real page/search and post data, then qualified enquiries; document what is observed vs plausible but unproven influence.

## Conversion bridge without fabricated attribution

- Give the customer one clear **next useful action**, not every CTA simultaneously: learn more, get a verified syllabus, visit, call, submit a form, book an appointment, or send a consent-based WhatsApp message.
- Ask only for genuine qualification details relevant to the service (e.g. course interest, preferred mode, district, experience level); avoid sensitive information and never pretend someone opted in.
- Make website/service page CTA content consistent with the Reel/blog promise.
- Track source at content level where possible using links with UTM parameters; store post IDs, landing page URL, click context and consent-aware CRM notes.
- For direct WhatsApp messages, consider a **pre-filled voluntary enquiry phrase** and ask “How did you find us?”; do not claim all WhatsApp conversions are attributable to Instagram or Google.
- Distinguish **platform-attributed / tracked / self-reported / assisted / unknown**. Never add overlapping categories as unique customers without deduplication.

## Suggested 30-day integrated workflow for a small team

- Week 1: verify business facts, choose 3 genuine customer questions, review real pages and profile status.
- Week 2: improve one high-intent page/FAQ; film one real demonstration Reel; create decision checklist carousel.
- Week 3: publish a second distinct question/pillar; answer comments with consent; ensure link and contact process work.
- Week 4: review GSC/GBP/social/CRM baseline if data exists; refine weak questions and measure qualified actions. Do not claim Google ranking changes within one month are causally attributable.

## QA gate: six practical checks

1. Original source is identifiable; no fabricated screenshots or student/customer quotes.
2. Every adaptation serves a **different information need**, not reworded same copy.
3. Search page intent fits; real page and location details are truthful.
4. CTA destination exists, is accessible and matches offer; otherwise marked placeholder.
5. Malayalam text reads naturally and has been proofread; speech timing approximated and rechecked.
6. Measurement specifies baseline/data source, time window, attribution certainty and true qualified lead definition.
