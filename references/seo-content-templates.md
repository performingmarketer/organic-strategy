# SEO content planning and production templates

## Keyword / page map

| Priority | Intent | Proposed customer query | Existing URL or proposed page | Page type | Original value / proof | CTA | Status | Evidence |
|---|---|---|---|---|---|---|---|---|

Use realistic search phrasing without fabricated search volume, rankings or keyword difficulty. If no crawl is available, URLs must be marked **Proposed, not verified**.

## Landing page brief

- Customer segment and conversion question
- One primary intent/topic and semantic related questions (no stuffing)
- Working slug, SEO title, H1, plain-English/Malayalam lead and differentiator
- Trust signals: genuine team expertise, service scope, verified pricing/availability, real work examples
- Recommended sections: problem; who it is for; how service works; evidence; FAQs; location/service coverage; clear next action
- Internal links: confirmed URLs vs targets to create
- Multimedia: original images/video/screenshots, descriptive alt text that matches actual image content
- Measurement: GSC target query/page, engaged visit, valid form/message, verified conversion
- What a reviewer must verify before publishing

## Blog brief

1. User intent and one-sentence answer.
2. Draft title/H1 (descriptive, not clickbait); likely audience questions.
3. Outline (H2/H3) that resolves the search need; no fixed word-count target.
4. Unique contributions required from expert/customer/business, cited sources if needed.
5. Internal links to real supporting pages, primary service path and next action.
6. Meta description as human-readable snippet candidate; not guaranteed to be used verbatim by Google.
7. Original featured image brief and factual alt text; image filename may be descriptive but does not guarantee ranking.
8. Quality/fact check, editor/author credit if appropriate, last reviewed date only if actually reviewed.
9. Repurposing into an informative short video, a carousel, FAQ, social post and optional GBP update.

## Page refresh template

Current URL (verified), baseline period, observed GSC queries/pages, actual page gaps vs hypotheses, planned change, owner, publication date, measurement date, result. Do not change publication dates to imply freshness if the substance was not updated.

## Blog-to-Reel repurposing

- Original blog insight: one exact customer problem and a defensible takeaway
- 0–3 sec: truthful relevant hook
- 3–10 sec: what the user should know
- 10–35 sec: explain/demonstrate with original evidence
- last ~5 sec: useful takeaway or honest CTA
- Caption: summarize value + context; use link in profile or platform-supported link features as applicable; do not say links are clickable in captions where not supported

## Content handoff

Require draft → fact check → specialist review as needed → language proofread → SEO/creative QA → publish → internal link/distribute → log performance. Avoid claiming live publish actions without authorized tools.
